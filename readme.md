# Ignite Gym Mobile

O app Ignite Gym, desenvolvido em React Native e Expo, busca contribuir para incentivar a prática de atividades físicas, indicando como realizar alguns exercícios e armazenando o histórico do usuário.

## Funcionalidades

- Listagem de exercícios agrupados por área do corpo
- Demonstração dos exercícios
- Histórico dos exercícios realizados
- Seleção e upload de foto de perfil
- Atualização de perfil do usuário
- Autorização e autenticação de usuário
- Integração com API Rest
- Validação de formulários com `yup` e `react-hook-form`
- Navegação com `react-navigation`

## Técnicas e Boas Práticas

- **Componentização**: Componentes reutilizáveis para manter o código organizado e modular.
- **Context API**: Gerenciamento de estado global utilizando Context API do React.
- **Hooks Personalizados**: Criação de hooks personalizados para reutilização de lógica.
- **Validação de Formulários**: Utilização de `react-hook-form` e `yup` para validação e gerenciamento de formulários.
- **Navegação**: Configuração de navegação utilizando `react-navigation`.

## Instalação

1. Clone o repositório:

    ```sh
    git clone https://github.com/seu-usuario/ignitegym-mobile.git
    ```

2. Navegue até o diretório do projeto:

    ```sh
    cd ignitegym-mobile
    ```

3. Instale as dependências:

    ```sh
    npm install
    ```

## Executando o Projeto

Para iniciar o projeto, utilize o comando:

```sh
npx expo start
```
